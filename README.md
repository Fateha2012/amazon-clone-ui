# Amazon Clone UI

A static Amazon homepage UI built for learning. Not affiliated with Amazon.

🔗 **Live demo:** https://fateha2012.github.io/amazon-clone-ui/

## Features

- Header with search bar and navigation
- Hero banner and category cards
- Footer with link columns
- Responsive layout using CSS Grid, Flexbox and media queries

## Built With

- HTML5
- CSS3

## Run Locally

Open `index.html` in your browser.
